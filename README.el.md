# Villa PMS

[English](README.md) · **Ελληνικά**

Αυτόνομο **WordPress plugin κρατήσεων** για ένα κατάλυμα βραχείας διαμονής (βίλα / διαμέρισμα). Διαχειρίζεται άμεσες online κρατήσεις με πληρωμές κάρτας μέσω **Stripe**, κρατά τη διαθεσιμότητα συγχρονισμένη με **Booking.com** και **Airbnb** μέσω **iCal**, και χειρίζεται επιστροφές χρημάτων, τιμές ανά ημέρα και emails προς τους επισκέπτες — χωρίς εξωτερικό channel manager ή SaaS.

Γραμμένο από το μηδέν σε καθαρή PHP πάνω στα APIs του WordPress. Τα μυστικά του Stripe αποθηκεύονται στις ρυθμίσεις του WordPress και δεν μπαίνουν ποτέ στον κώδικα.

> Σε παραγωγή στο [isleofolive.gr](https://isleofolive.gr) (Isle of Olive, Κέρκυρα).

## Λειτουργίες

**Κρατήσεις & πληρωμές**
- Ημερολόγιο κρατήσεων στο frontend με το shortcode `[villa_booking]`
- Stripe Checkout (κάρτες + Apple/Google Pay), με **server-side επαλήθευση** session, booking id, ακριβούς ποσού σε cents και νομίσματος πριν χαρακτηριστεί μια κράτηση πληρωμένη
- Υποχρεωτική **επαλήθευση υπογραφής webhook** του Stripe — μη υπογεγραμμένα events απορρίπτονται
- Σύντομο κράτημα ημερομηνιών για pending κρατήσεις (~40') με grace period ώστε καθυστερημένα webhooks να επιβεβαιώνονται κανονικά
- Rate limiting στο δημόσιο endpoint (10 προσπάθειες / 15'), χωρίς αποθήκευση IP σε αναγνώσιμη μορφή

**Επιστροφές χρημάτων**
- Πλήρεις επιστροφές μέσω του Stripe Refund API με **idempotency key ανά προσπάθεια**
- Η κατάσταση επιστροφής παρακολουθείται **ξεχωριστά** από το booking status, με αυτόματη ωριαία συμφωνία (reconciliation) με το Stripe
- Άγνωστο/κενό refund status δεν θεωρείται ποτέ επιτυχία· αποτυχίες εγγραφής εμφανίζονται ως ρητά reconciliation warnings

**Συγχρονισμός καναλιών (iCal)**
- Δύο ξεχωριστά export feeds, το καθένα με δικό του μυστικό token: το feed του Airbnb περιλαμβάνει τις κρατήσεις Booking.com και αντίστροφα, ώστε μια κράτηση στη μία πλατφόρμα να μπλοκάρει την άλλη
- Χωρίς βρόχο συγχρονισμού: τα δικά μας events έχουν UID με πρόθεμα `vpms-` και αγνοούνται στο import
- Συγχρονισμός κάθε 15 λεπτά (ή χειροκίνητα)· κατάσταση ανά feed στο admin

**Τιμές, email & απόρρητο**
- Τιμές ανά ημέρα πάνω από μια προεπιλεγμένη τιμή/νύχτα, ελάχιστες/μέγιστες νύχτες, μέγιστα άτομα, έξοδα καθαρισμού, νόμισμα
- Emails προς επισκέπτες και ιδιοκτήτη (επιβεβαίωση, άφιξη, ευχαριστήριο) από ρυθμιζόμενο αποστολέα
- GDPR: καταγραφή συγκατάθεσης server-side, διαγραφή/ανωνυμοποίηση δεδομένων ανά κράτηση, ενσωμάτωση με το Export/Erase Personal Data του WordPress· τα iCal feeds και τα logs δεν περιέχουν ποτέ προσωπικά δεδομένα

## Τεχνολογίες

| | |
|---|---|
| Πλατφόρμα | WordPress plugin, καθαρή PHP (απαιτεί PHP 8.1+) |
| Πληρωμές | Stripe Checkout + Refund API, υπογεγραμμένα webhooks |
| Συγχρονισμός | iCal export/import, WP-Cron (ή πραγματικό server cron) |
| Αποθήκευση | Custom πίνακες μέσω `dbDelta`, idempotent migrations |
| Πρόσβαση δεδομένων | REST endpoints (`vpms/v1`), nonces, server-side validation |

## Εγκατάσταση

WordPress admin → Πρόσθετα → Προσθήκη νέου → Μεταφόρτωση → ανέβασε τον φάκελο του plugin ως zip και ενεργοποίησε. Η πλήρης ρύθμιση (κλειδιά Stripe, webhook endpoint, iCal feeds, τιμές) περιγράφεται αναλυτικά στο **[INSTALL.el.md](INSTALL.el.md)**.
